Contextual Search

Audit of the live coach.ae search and the recommended design: a contextual-search icon, an animated placeholder, a first-visit tip, and active states that show what the search understood. Boards marked Prototype are clickable.

Current state

The live coach.ae search on desktop: a plain field, and an active panel with products and Popular searches.

Recommended · default state

A sparkle icon, an animated “Search ‘…’” placeholder with COACH sample queries, and a one-time tip on first visit.

Recommended · active states

The open panel teaches contextual search; while typing, the panel shows what the search understood as removable tags.

Mobile · current state

The live mobile search: icon-only header, left drawer, and a typing state with unrelated suggestions.

Mobile · recommended

Header from the COACH 2024 library (sparkles + search), a full-screen search sheet, and the same contextual states as desktop.

Desktop · 992px breakpoint

Content width 928px; field 220px at rest and 255px when focused, 32px from the logo.
