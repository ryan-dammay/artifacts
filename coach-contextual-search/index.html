Contextual Search

Recommended design for contextual search on coach.ae: a contextual-search icon, an animated placeholder, a first-visit tip, and active states that show what the search understood. Boards marked Prototype are clickable.

Recommended · active states that show the search understands context

Mobile · recommended

Mobile notes

  • Header icon uses the contextual-search glyph (option B): icon-only, so the sparkle sits inside the lens.
  • Search opens as a full-screen sheet instead of the left drawer: more room, one Cancel instead of back + ✕, and clearing the query never drops into the menu.
  • First-visit tip waits until the sign-up pop-up is closed.
  • Input text is 17px so iOS doesn’t zoom the page on focus.
  • Product data in the typing state is demo data.

Desktop · 992px breakpoint

992px notes

  • Content width 928px (32px side margins).
  • Search field 220px at rest, 300px when focused (live site: ~118px / ~250px).
  • Panel columns 300px + fluid, 40px gap; 3 product cards stay.
  • First-visit tip 260px wide, arrow centred on the 220px field.
  • Long queries scroll on one line, as at 1440px.
Designed in Claude; this GitHub copy runs the same boards with a small stand-in runtime (source/dc-lite.js). Products and prices are from coach.ae at the time of the design; product data in the typing states is demo data.
